# @trypitchdotco Viral Mention-Demo Bot Playbook (Instant Receipt + Rendered S3 Video Reply)

This playbook operates `@trypitchdotco`'s automated viral mention demo bot using **Instant Acknowledgement** + **Pitch MCP API (`https://api.trypitch.co/mcp`)** + **Official X API v2**.

## Instant Receipt & Delivery Sequence

1. **Step 1: Instant Receipt Reply (<1 Second)**
   - As soon as a user tweets `@trypitchdotco` with a product URL/domain, immediately post an instant acknowledgment reply on X via official API:
     > *"Cool @username, we're on it! 🚀 Generating your cinematic demo for [URL] now, we'll get back to you with the video link right here soon!"*

2. **Step 2: Submit Video Job via Pitch MCP API**
   - Triggers Pitch MCP tool `create_demo_video` for the target URL.
   - Captures returned `jobId`.

3. **Step 3: Track Job & Deliver Final Rendered Video S3 Link**
   - Polls MCP job status via `python3 /home/adnan/x_bot/bin/pitch_mcp.py status [JOB_ID]` until status is `COMPLETED`.
   - Posts second reply on X with native MP4 attachment / direct S3 video link:
     > *"Here is your product demo @username generated by @trypitchdotco! Hope you enjoy it: https://s3.trypitch.co/trypitch/pitch/user_.../videos/.../final_with_cards.mp4 🎬"*
